# mbm shell v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace waybar, walker/elephant, mako, swayosd, swaybg, hyprlock, hypridle and polkit-gnome with one Quickshell shell (`qs -c mbm`), plus a settings window whose changes go through a tested `mbm settings` CLI that generates Hyprland config.

**Architecture:** QML (Quickshell 0.3.1) renders and handles interaction, using Quickshell's built-in services (Hyprland, PipeWire, UPower, Networking, Bluetooth, Notifications, SystemTray, PAM, Polkit, IdleMonitor). Everything that writes config goes through `mbm settings` (bash + jq): shipped defaults + user overrides → merged state file (read live by the shell) + generated `~/.config/hypr/mbm/*.conf`. Binds reach the shell with `qs -c mbm ipc call <target> <fn>`.

**Tech Stack:** Quickshell 0.3.1 (`extra`), QML/Qt 6, bash, jq, cliphist, brightnessctl, systemd user units, GNU stow, libvirt test VM.

**Spec:** `docs/superpowers/specs/2026-10-10-mbm-shell-design.md`. Read it with this plan. Task 1 amends it where research during planning changed the design.

## Global Constraints

- **Never change the host machine.** Nothing from this project is run, stowed, installed or reloaded on the host. Every command that runs project code, unit tests included, goes through `cachyos/vm/vm.sh` (Task 1) into the `cachyos-test` VM. Reading host files and `pacman -Si` are fine.
- Brand: made by moonlight. New names use `mbm`. Never "slievr" as a brand.
- No webapps. Don't add or port webapp support. Existing webapp binds are left untouched.
- Quickshell version: `quickshell` 0.3.1 from `extra`. The API source of truth is the `.qmltypes` files under `/usr/lib/qt6/qml/Quickshell/` in the VM (a host-side extract is in `.superpowers/quickshell-0.3.1-api.txt`).
- Palette (from `dot-config/omarchy/current/theme/colors.toml`): background `#171e28`, raised `#212a33`, surface `#2f3640`, fg `#ffffff`, dim `#c8ced8`, muted `#6c7787`, accent amber `#f4af03`, error `#e5626a`, ok `#8fcf8a`. Font `JetBrainsMono Nerd Font`.
- Paths: shell `dot-config/quickshell/mbm/` → `~/.config/quickshell/mbm/`; CLI `dot-local/share/mbm/` → `~/.local/share/mbm/`; user overrides `~/.config/mbm/settings.json`; merged state `~/.local/state/mbm/settings.json`; generated Hyprland config `~/.config/hypr/mbm/{binds,monitors,input}.conf`.
- Hyprland 0.56. Keep everything the settings own generated (0.57 drops `.conf`; Quickshell's `Hyprland.usingLua` already exists).
- Launch apps through `uwsm app --` so they live outside the shell's systemd cgroup (restarting the shell must never kill apps).
- Bash: `set -euo pipefail` in executables, shellcheck clean at `-S warning`, comments explain why, tests use `cachyos/install/test/lib.sh` (`check`, `contains`, `exit $fail`).
- Commits: `area: what and why`, lowercase area (`mbm:`, `shell:`, `vm:`, `hypr:`, `bootstrap:`, `docs:`). Commit at the end of every task (more often is fine). Don't push.

## Review Focus

1. **Hand-edited, broken `~/.config/mbm/settings.json`.** The shell must still start and look normal (it keeps the last good merged state, or defaults), `mbm settings check` names the problem, and `apply` changes nothing. Test: Task 3 (CLI) + Task 7 Step 6 (shell).
2. **Recording a key the compositor already binds** (e.g. Super+Space in the Keybinds page). Without care Hyprland fires the launcher instead of the recorder seeing the keys, and a crashed shell could strand the user in the recording submap. Test: Task 16 Steps 5–6.
3. **Monitor hotplug.** Bar and wallpaper must appear on a new output and disappear with it, without restarting the shell. Test: Task 8 Step 6.
4. **Locking while a popup holds keyboard focus** (launcher or quick settings open, or a dmenu waiting). The lock must take focus, close popups, and cancel the dmenu (its caller gets exit 1, not a hang). Test: Task 14 Step 7.
5. **Notification flood** (50 `notify-send` in a loop). At most 5 pop-ups visible, all 50 in history, shell stays responsive. Test: Task 10 Step 5.

- [ ] **Step 1: Write `cachyos/vm/vm.sh`**

```bash
#!/usr/bin/env bash
# Drive the cachyos-test VM from the host: sync the working tree in, run
# commands inside the logged-in Hyprland session, take screenshots. All
# project code runs in the VM, never on the host (AGENTS.md rule 1).
#   vm.sh ip | sync | restow | shell | run CMD... | sudo CMD... | shot NAME | type TEXT | relogin
set -euo pipefail

VM_NAME="cachyos-test"
VM_USER="${VM_USER:-slievr}"
VM_PASSWORD="${VM_PASSWORD:-TestPass1}"
VIRSH="virsh -c qemu:///system"
REPO="$(cd "$(dirname "$(realpath "${BASH_SOURCE[0]}")")/../.." && pwd)"
VM_REPO="proj/slievr-cachy"

vm_ip() {
  local ip
  ip="$($VIRSH domifaddr "$VM_NAME" 2>/dev/null | awk '/ipv4/{print $4}' | cut -d/ -f1 | head -n1)"
  [[ -n $ip ]] || { echo "vm.sh: no IP for $VM_NAME (run cachyos/vm/dev-up.sh first)" >&2; exit 1; }
  printf '%s\n' "$ip"
}

ssh_vm() { ssh -o BatchMode=yes -o ConnectTimeout=5 "$VM_USER@$(vm_ip)" "$@"; }

# Session env for commands run over SSH: the Wayland socket and Hyprland
# instance of the user's graphical login, plus the project bin dirs.
SESSION_ENV='export XDG_RUNTIME_DIR=/run/user/$(id -u)
w=$(ls -1 "$XDG_RUNTIME_DIR" 2>/dev/null | grep -E "^wayland-[0-9]+$" | head -n1); [ -n "$w" ] && export WAYLAND_DISPLAY=$w
h=$(ls -1t "$XDG_RUNTIME_DIR/hypr" 2>/dev/null | head -n1); [ -n "$h" ] && export HYPRLAND_INSTANCE_SIGNATURE=$h
export DBUS_SESSION_BUS_ADDRESS=unix:path=$XDG_RUNTIME_DIR/bus
export PATH=$HOME/.local/share/mbm/bin:$HOME/.local/share/slievr-cachy/bin:$PATH'

cmd_sync() {
  cd "$REPO"
  local list
  list="$(git ls-files -co --exclude-standard)"
  # Delete files the VM copy has that the host no longer does (renames, cutover deletions).
  ssh_vm "mkdir -p ~/$VM_REPO && cd ~/$VM_REPO && comm -23 <(git ls-files -co --exclude-standard 2>/dev/null | sort) <(sort) | xargs -r -d '\n' rm -f --" <<<"$list"
  printf '%s\n' "$list" | tar -czf - -T - | ssh_vm "tar -xzf - -C ~/$VM_REPO"
}

case "${1:-}" in
  ip) vm_ip ;;
  sync) cmd_sync ;;
  restow) cmd_sync; ssh_vm "cd ~/$VM_REPO && stow --dotfiles -R -v -t ~ . 2>&1 | grep -v '^LINK\|^UNLINK' || true" ;;
  run) shift; ssh_vm "$SESSION_ENV"$'\n'"$*" ;;
  sudo) shift; printf '%s\n' "$VM_PASSWORD" | ssh_vm "$SESSION_ENV"$'\n'"sudo -S -p '' sh -c $(printf '%q' "$*")" ;;
  shell)
    # Dev loop before Task 18 installs the service: stop the old UI daemons
    # (mako owns the notification bus name, waybar overlaps the bar), restart qs.
    ssh_vm "$SESSION_ENV"$'\n''pkill -x waybar; pkill -x mako; pkill -x swayosd-server; pkill -x hypridle
      if systemctl --user is-active -q mbm-shell 2>/dev/null; then systemctl --user restart mbm-shell; sleep 3; journalctl --user -u mbm-shell -b --no-pager | grep -E "WARN|ERROR" | tail -n 40
      else qs -c mbm kill >/dev/null 2>&1; sleep 0.5; setsid -f qs -c mbm >/tmp/mbm.log 2>&1 </dev/null; sleep 3; grep -E "WARN|ERROR" /tmp/mbm.log | tail -n 40; fi; true' ;;
  shot)
    name="${2:?vm.sh shot NAME}"; mkdir -p "$REPO/.superpowers/shots"
    ssh_vm "$SESSION_ENV"$'\n'"grim /tmp/$name.png" && scp -q "$VM_USER@$(vm_ip):/tmp/$name.png" "$REPO/.superpowers/shots/$name.png"
    echo "$REPO/.superpowers/shots/$name.png" ;;
  type)
    # Type into the VM's console (LUKS prompt, SDDM) with virsh send-key, then Enter.
    shift; text="$*"
    for ((i = 0; i < ${#text}; i++)); do
      c="${text:i:1}"
      case "$c" in
        [a-z]) $VIRSH send-key "$VM_NAME" "KEY_${c^^}" >/dev/null ;;
        [A-Z]) $VIRSH send-key "$VM_NAME" KEY_LEFTSHIFT "KEY_$c" >/dev/null ;;
        [0-9]) $VIRSH send-key "$VM_NAME" "KEY_$c" >/dev/null ;;
        ' ') $VIRSH send-key "$VM_NAME" KEY_SPACE >/dev/null ;;
        *) echo "vm.sh type: can't type '$c'" >&2; exit 1 ;;
      esac
    done
    $VIRSH send-key "$VM_NAME" KEY_ENTER >/dev/null ;;
  relogin)
    # End the session and log back in at SDDM by typing the password.
    ssh_vm "$SESSION_ENV"$'\n''(uwsm stop >/dev/null 2>&1 &)' || true
    sleep 10; "$0" type "$VM_PASSWORD"; sleep 12
    ssh_vm "$SESSION_ENV"$'\n''hyprctl version >/dev/null && echo "logged in"' ;;
  *) sed -n '2,6p' "$0" >&2; exit 2 ;;
esac
```

### Task 3: `mbm settings` get/set/reset

**Files:**
- Create: `dot-local/share/mbm/bin/mbm`, `dot-local/share/mbm/lib/settings.sh`, `dot-local/share/mbm/lib/check.jq` (stub: no rules yet), `dot-local/share/mbm/test/test-settings.sh`, `dot-local/share/mbm/test/fixtures/defaults.json`

**Interfaces:**
- Produces (CLI): `mbm settings get [PATH]` → merged JSON at PATH (default `.`), exit 1 on unreadable user file. `mbm settings set PATH JSON [PATH JSON]…` → writes overrides atomically and refreshes the merged state; refuses invalid paths, non-JSON values, or results that fail `check` (nothing written). `mbm settings reset PATH…` → deletes overrides.
```bash
# shellcheck shell=bash
# mbm settings: shipped defaults + the user's overrides -> one merged state
# file (read live by the shell) + generated Hyprland config. The merge and the
# validation live only here, so the shell and bootstrap can't disagree.
# Every path can be overridden from the environment (the tests use a temp HOME).

MBM_DEFAULTS="${MBM_DEFAULTS:-$MBM_ROOT/defaults/settings.json}"
MBM_CONFIG_DIR="${MBM_CONFIG_DIR:-$HOME/.config/mbm}"
MBM_STATE_DIR="${MBM_STATE_DIR:-$HOME/.local/state/mbm}"
MBM_HYPR_DIR="${MBM_HYPR_DIR:-$HOME/.config/hypr/mbm}"
MBM_USER="$MBM_CONFIG_DIR/settings.json"
MBM_MERGED="$MBM_STATE_DIR/settings.json"

die() { printf 'mbm: %s\n' "$*" >&2; exit 1; }

# atomic_write <file>: stdin -> temp file beside <file>, then mv, so readers
# (Hyprland, the shell's file watcher) never see a half-written file.
atomic_write() {
  local dest="$1" tmp
  mkdir -p "$(dirname "$dest")"
  tmp="$(mktemp "$dest.XXXXXX")"
  if cat >"$tmp"; then
    mv -f "$tmp" "$dest"
  else
    rm -f "$tmp"
    return 1
  fi
}

# Only jq *paths* are accepted (.a.b, .a["id.with.dots"]), never arbitrary
# filters: the settings window passes these through.
valid_path() {
  local re='^(\.[A-Za-z_][A-Za-z0-9_]*|\["[^"\\]*"\])+$'
  [[ $1 =~ $re ]]
}

user_json() { # the overrides, or {} when there are none
  if [[ -f $MBM_USER ]]; then
    jq -e 'if type == "object" then . else error("not an object") end' "$MBM_USER" 2>/dev/null \
      || die "$MBM_USER is not a valid JSON object"
  else
    echo '{}'
  fi
}

# merge <user-json>: defaults * overrides; a bind overridden with null is removed.
merge() {
  jq -n --slurpfile d "$MBM_DEFAULTS" --argjson u "$1" \
    '($d[0] * $u) | .binds |= with_entries(select(.value != null))'
}

merged_json() {
  local user
  user="$(user_json)" || exit 1
  merge "$user"
}

# check_json <merged-json>: 0 when valid; one problem per line on stderr.
check_json() {
  local errs
  errs="$(jq -r -f "$MBM_ROOT/lib/check.jq" <<<"$1")" || return 1
  [[ -z $errs ]] && return 0
  printf '%s\n' "$errs" >&2
  return 1
}

refresh_state() {
  local out
  out="$(merged_json)" || exit 1
  printf '%s\n' "$out" | atomic_write "$MBM_MERGED"
}

# write_user <new-user-json>: validate the merged result first; write nothing if it fails.
write_user() {
  local merged
  merged="$(merge "$1")" || die "could not merge settings"
  check_json "$merged" || die "change refused: the settings would be invalid"
  printf '%s\n' "$1" | atomic_write "$MBM_USER"
  printf '%s\n' "$merged" | atomic_write "$MBM_MERGED"
}

settings_get() {
  local path="${1:-.}"
  [[ $path == . ]] || valid_path "$path" || die "bad settings path: $path"
  local merged
  merged="$(merged_json)" || exit 1
  jq "$path" <<<"$merged"
}

settings_set() {
  (($# >= 2 && $# % 2 == 0)) || die "usage: mbm settings set <path> <json> [<path> <json>]..."
  local user filter='.' i=0 out
  local -a args=()
  user="$(user_json)" || exit 1
  while (($#)); do
    valid_path "$1" || die "bad settings path: $1"
    jq -n --argjson v "$2" 'true' >/dev/null 2>&1 || die "not JSON: $2"
    filter+=" | setpath(path($1); \$v$i)"
    args+=(--argjson "v$i" "$2")
    i=$((i + 1))
    shift 2
  done
  out="$(jq "${args[@]}" "$filter" <<<"$user")" || die "could not apply the change"
  write_user "$out"
}

settings_reset() {
  (($# >= 1)) || die "usage: mbm settings reset <path>..."
  local user filter='.' out p
  user="$(user_json)" || exit 1
  for p in "$@"; do
    valid_path "$p" || die "bad settings path: $p"
    filter+=" | delpaths([path($p)])"
  done
  out="$(jq "$filter" <<<"$user")" || die "could not reset"
  write_user "$out"
}

settings_main() {
  local sub="${1:-}"
  shift || true
  case "$sub" in
    get) settings_get "$@" ;;
    set) settings_set "$@" ;;
    reset) settings_reset "$@" ;;
    *) die "usage: mbm settings get|set|reset|check|apply" ;;
  esac
}
```

```jq
# Kept in step with the schema in docs/superpowers/specs/2026-10-10-mbm-shell-design.md.

def isint: type == "number" and . == floor;
def str_matches($re): type == "string" and test($re);
def unknown($allowed; $where): (keys - $allowed)[] | "\($where): unknown field \(.)";
def mods_list: split(" ") | map(select(. != ""));
def mods_ok: type == "string" and (mods_list | all(IN("SUPER", "SHIFT", "CTRL", "ALT", "MOD2", "MOD3", "MOD5")));
def action_ok:
  type == "object"
  and ((keys - ["shell", "dispatch", "exec"]) | length) == 0
  and ([.shell, .dispatch, .exec] | map(select(. != null)) | length == 1 and (.[0] | type == "string" and length > 0));
# What Hyprland treats as "the same keys": modifiers in any order, key case-insensitively, same flags.
def combo: (.mods | mods_list | sort | join("+")) + "+" + (.key | ascii_downcase)
           + "/" + ((.flags // "") | gsub("d"; "") | split("") | sort | join(""));

def check_bind($id):
  . as $b
  | if type != "object" then "binds.\($id): must be an object"
    else
      unknown(["mods", "key", "flags", "label", "group", "action"]; "binds.\($id)"),
      (if ($b.mods | mods_ok) then empty else "binds.\($id): bad modifiers \($b.mods | tojson)" end),
      (if ($b.key | type == "string" and length > 0) then empty else "binds.\($id): key is required" end),
      (if ($b.flags // "" | str_matches("^[elrnmtisp]*$")) then empty else "binds.\($id): bad flags \($b.flags | tojson)" end),
      (if ($b.label | type == "string" and (test(",") | not)) then empty else "binds.\($id): label must be a string without commas" end),
      (if ($b.group | type == "string") then empty else "binds.\($id): group is required" end),
      (if ($b.action | if type == "array" then length > 0 and all(action_ok) else action_ok end) then empty
       else "binds.\($id): action must be one of {shell}, {dispatch}, {exec} (or a list of them)" end)
    end;

def check_display($name):
  . as $d
  | unknown(["mode", "position", "scale", "transform", "enabled"]; "displays.\($name)"),
    (if ($d.mode // "preferred" | str_matches("^(preferred|highres|highrr|[0-9]+x[0-9]+(@[0-9]+(\\.[0-9]+)?)?)$")) then empty
     else "displays.\($name): bad mode \($d.mode | tojson)" end),

     else "displays.\($name): bad position \($d.position | tojson)" end),
    (if ($d.scale // "auto" | . == "auto" or (type == "number" and . > 0)) then empty
     else "displays.\($name): bad scale \($d.scale | tojson)" end),
    (if ($d.transform // 0 | isint and . >= 0 and . <= 7) then empty
     else "displays.\($name): bad transform \($d.transform | tojson)" end),
    (if ($d.enabled // true | type == "boolean") then empty else "displays.\($name): enabled must be true or false" end);

def modules($side):

  | if type != "array" then "bar.\($side) must be a list"
    else .[] | select(IN("workspaces", "title", "clock", "tray", "glyphs", "cog", "media") | not) | "bar.\($side): unknown module \(tojson)"
    end;

def secs($k): if (.[$k] // 0 | isint and . >= 0) then empty else "idle.\($k) must be a whole number of seconds >= 0" end;

(keys - ["version", "binds", "displays", "bar", "launcher", "notifications", "idle", "input"])[] | "unknown setting: \(.)",
```

```bash
#!/usr/bin/env bash
# One-off migration: Hyprland bind lines -> the "binds" object of mbm settings.
#   conf-to-binds.sh Group=file.conf [Group=file.conf]...  > binds.json
# Files are read in the order Hyprland sources them: `unbind` drops an earlier
# bind on the same mods+key, `$var = value` lines are expanded, and several
# binds on one combo become one entry with a list of actions.
set -euo pipefail

declare -A vars=()
records=""

trim() { local s="$1"; s="${s#"${s%%[![:space:]]*}"}"; s="${s%"${s##*[![:space:]]}"}"; printf '%s' "$s"; }
norm_mods() { trim "$1" | tr '[:lower:]' '[:upper:]' | tr -s ' '; }
expand() { local s="$1" k; for k in "${!vars[@]}"; do s="${s//\$$k/${vars[$k]}}"; done; printf '%s' "$s"; }

for spec in "$@"; do
  group="${spec%%=*}" file="${spec#*=}"
  while IFS= read -r line || [[ -n $line ]]; do
    line="$(trim "${line%%#*}")"
    [[ -z $line ]] && continue
    if [[ $line =~ ^\$([A-Za-z_][A-Za-z0-9_]*)[[:space:]]*=[[:space:]]*(.*)$ ]]; then
      vars[${BASH_REMATCH[1]}]="$(trim "${BASH_REMATCH[2]}")"
    elif [[ $line =~ ^unbind[[:space:]]*=[[:space:]]*(.*)$ ]]; then
      IFS=, read -r mods key _ <<<"${BASH_REMATCH[1]}"
      records+="$(jq -cn --arg m "$(norm_mods "$mods")" --arg k "$(trim "$key")" '{unbind: true, mods: $m, key: $k}')"$'\n'
    elif [[ $line =~ ^bind([a-z]*)[[:space:]]*=[[:space:]]*(.*)$ ]]; then
      flags="${BASH_REMATCH[1]}" body="$(expand "${BASH_REMATCH[2]}")"
      IFS=, read -r mods key rest <<<"$body"
      if [[ $flags == *d* ]]; then
        IFS=, read -r label disp args <<<"$rest"
      else
        IFS=, read -r disp args <<<"$rest"
        label="$(trim "$disp") $(trim "$args")"
      fi
      records+="$(jq -cn --arg g "$group" --arg m "$(norm_mods "$mods")" --arg k "$(trim "$key")" \
        --arg f "${flags//d/}" --arg l "$(trim "${label//,/}")" --arg d "$(trim "$disp")" --arg a "$(trim "$args")" \
        '{group: $g, mods: $m, key: $k, flags: $f, label: $l, dispatcher: $d, args: $a}')"$'\n'
    fi
  done <"$file"
done

printf '%s' "$records" | jq -s '
  def slug: ascii_downcase | gsub("[^a-z0-9]+"; "-") | gsub("^-|-$"; "");
  def ckey: "\(.mods)|\(.key | ascii_downcase)|\(.flags)";
  def action: if .dispatcher == "exec" then {exec: .args}
              else {dispatch: ([.dispatcher, .args] | map(select(. != "")) | join(" "))} end;
  reduce .[] as $r ([];
    if $r.unbind then map(select((.mods == $r.mods and (.key | ascii_downcase) == ($r.key | ascii_downcase)) | not))
    else ($r | ckey) as $k | (map(ckey) | index($k)) as $i
      | if $i == null then . + [$r + {actions: [$r | action]}] else .[$i].actions += [$r | action] end
    end)
  | reduce .[] as $e ({};
      . as $acc
      | (($e.group | slug) + "." + ($e.label | slug)) as $base
      | first($base, (range(2; 1000) | "\($base)-\(.)") | select(. as $c | $acc | has($c) | not)) as $id
      | .[$id] = ({mods: $e.mods, key: $e.key, label: $e.label, group: $e.group,
                   action: (if ($e.actions | length) == 1 then $e.actions[0] else $e.actions end)}
                  + (if $e.flags != "" then {flags: $e.flags} else {} end)))'
```

```bash
#!/usr/bin/env bash
# Compare two `hyprctl binds -j` dumps (before/after the cutover). Prints each
# bind only one side has; exits 1 if any of them isn't explained by
# parity-allowed.txt (the deliberate remaps).
set -euo pipefail
HERE="$(cd "$(dirname "$(realpath "${BASH_SOURCE[0]}")")" && pwd)"
norm() { jq -r '.[] | "\(.modmask) \(.key | ascii_downcase) \(.submap // "") :: \(.dispatcher) \(.arg)"' "$1" | sort; }

unexplained="$(grep -vEf "$HERE/parity-allowed.txt" <<<"$diffs" | grep . || true)"
if [[ -n $unexplained ]]; then
  printf '\nUnexplained differences:\n%s\n' "$unexplained" >&2
  exit 1
```

```qml
// Which popups are open. Every opener goes through here so only one popup
// holds the keyboard at a time and a pending dmenu is always answered.
Singleton {
    id: root

    property bool barVisible: true
    property bool launcherOpen: false
    property string launcherMode: "apps"
    property bool qsOpen: false
    property string qsPicker: ""
    property bool settingsOpen: false
    property string settingsPage: "keybinds"
    property var dmenu: null
    property bool locked: false

    function focusedScreen() {
        const name = Hyprland.focusedMonitor?.name;
        return Quickshell.screens.find(s => s.name === name) ?? Quickshell.screens[0];
    }

    function closePopups() {
        if (dmenu) dmenuCancel();
        launcherOpen = false;
        qsOpen = false;
    }
    function openLauncher(mode) {
        closePopups();
        launcherMode = mode || "apps";
        launcherOpen = true;
    }
    function toggleLauncher(mode) {
        if (launcherOpen && (!mode || mode === launcherMode)) closePopups();
        else openLauncher(mode);
    }
    function openQuickSettings(picker) {
        closePopups();
        qsPicker = picker || "";
        qsOpen = true;
    }
    function toggleQuickSettings() {
        if (qsOpen) qsOpen = false;
        else openQuickSettings("");
    }
    function openSettings(page) {
        closePopups();
        settingsPage = page || "keybinds";
        settingsOpen = true;
    }

    // dmenu: `mbm dmenu` waits on resultFile (a FIFO) for "1\n<choice>\n" or "0\n\n".
    function dmenuOpen(req) {
        closePopups();
        dmenu = req;
        launcherMode = "dmenu";
        launcherOpen = true;
    }
    function dmenuFinish(ok, value) {
        const req = dmenu;
        dmenu = null;
        launcherOpen = false;
        if (!req) return;
        Quickshell.execDetached(["sh", "-c", 'printf "%s\\n%s\\n" "$1" "$2" > "$3"', "sh", ok ? "1" : "0", value ?? "", req.resultFile]);
    }
    function dmenuCancel() { dmenuFinish(false, ""); }
}
```

```qml
pragma Singleton
import Quickshell
import Quickshell.Io
import QtQuick

// Read side: the merged state file written by `mbm settings` (one merge, in the
// CLI). Write side: always through the CLI, so validation lives in one place.
// A file that can't be parsed is ignored and the last good value kept.
Singleton {
    id: root

    readonly property string home: Quickshell.env("HOME")
    readonly property string mbm: home + "/.local/share/mbm/bin/mbm"
    property var defaults: ({})
    property var merged: ({})
    property var user: ({})
    property string lastError: ""
    readonly property bool busy: writer.running

    function parse(text, fallback, what) {
        try {
            const v = JSON.parse(text);
            if (v && typeof v === "object" && !Array.isArray(v)) return v;
        } catch (e) {}
        console.warn("mbm settings: ignoring unreadable " + what);
        return fallback;
    }

    FileView {
        path: root.home + "/.local/share/mbm/defaults/settings.json"
        watchChanges: true
        onFileChanged: reload()
        onLoaded: root.defaults = root.parse(text(), root.defaults, path)
    }
    FileView {
        path: root.home + "/.local/state/mbm/settings.json"
        watchChanges: true
        onFileChanged: reload()
        onLoaded: root.merged = root.parse(text(), root.merged, path)
    }
    FileView {
        path: root.home + "/.config/mbm/settings.json"
        watchChanges: true
        onFileChanged: reload()
        onLoaded: root.user = root.parse(text(), root.user, path)
        onLoadFailed: root.user = ({})
    }

    // merged → defaults → fallback (merged is empty on a first boot before `apply`).
    function get(section, key, fallback) {
        const m = merged?.[section]?.[key];
        if (m !== undefined) return m;
        const d = defaults?.[section]?.[key];
        return d !== undefined ? d : fallback;
    }

    readonly property var binds: merged.binds ?? defaults.binds ?? ({})
    readonly property string barPosition: get("bar", "position", "top")
    readonly property var barLeft: get("bar", "left", ["workspaces", "title"])
    readonly property var barCentre: get("bar", "centre", ["clock"])
    readonly property var barRight: get("bar", "right", ["tray", "glyphs", "cog"])
    readonly property var barGlyphs: get("bar", "glyphs", ["network", "battery"])
    readonly property string launcherPosition: get("launcher", "position", "centre")
    readonly property string notifCorner: get("notifications", "corner", "top-right")
    readonly property int notifTimeout: get("notifications", "timeoutMs", 5000)
    readonly property int idleDim: get("idle", "dimSec", 0)
    readonly property int idleLock: get("idle", "lockSec", 0)
    readonly property int idleScreenOff: get("idle", "screenOffSec", 0)
    readonly property int idleSuspend: get("idle", "suspendSec", 0)
    readonly property bool lockOnSleep: get("idle", "lockOnSleep", true)

    signal writeFinished(bool ok, string error)

    function set(pairs, apply) {
        const args = [root.mbm, "settings", "set"];
        for (const p of pairs) args.push(p[0], JSON.stringify(p[1]));
        run(args, apply);
    }
    function reset(paths, apply) { run([root.mbm, "settings", "reset", ...paths], apply); }
    function run(args, apply) {
        if (writer.running) return;
        writer.command = apply ? ["sh", "-c", '"$@" && "$0" settings apply', root.mbm, ...args] : args;
        writer.running = true;
    }

    Process {
        id: writer
        stderr: StdioCollector { id: writerErr }
        onExited: code => {
            root.lastError = code === 0 ? "" : writerErr.text.trim();
            root.writeFinished(code === 0, root.lastError);
        }
    }
}
```

- [ ] **Step 1: Write the services**

`services/Audio.qml`:
```qml
pragma Singleton
import Quickshell
import Quickshell.Services.Pipewire
import QtQuick

Singleton {
    id: root
    readonly property var sink: Pipewire.defaultAudioSink
    readonly property var source: Pipewire.defaultAudioSource
    readonly property bool ready: sink?.audio != null
    readonly property real volume: sink?.audio?.volume ?? 0
    readonly property bool muted: sink?.audio?.muted ?? true
    readonly property real micVolume: source?.audio?.volume ?? 0
    readonly property bool micMuted: source?.audio?.muted ?? true
    readonly property var sinks: Pipewire.nodes.values.filter(n => n.audio && n.isSink && !n.isStream)
    readonly property var sources: Pipewire.nodes.values.filter(n => n.audio && !n.isSink && !n.isStream)

    // Volume/mute of a node are only live while something tracks it.
    PwObjectTracker { objects: [root.sink, root.source, ...root.sinks, ...root.sources] }

    function clamp(v) { return Math.max(0, Math.min(1, v)); }
    function setVolume(v) { if (sink?.audio) { sink.audio.muted = false; sink.audio.volume = clamp(v); } }
```

```qml
pragma Singleton
import Quickshell
import Quickshell.Services.Notifications
import QtQuick

// One notification server for the session. Every notification is tracked
// (history); pop-ups are the newest few. DND keeps them out of pop-ups only.
Singleton {
    id: root
    property bool dnd: false
    property var popups: []
    property var lastDismissed: null
    readonly property var history: server.trackedNotifications.values
    readonly property int maxPopups: 5

    NotificationServer {
        id: server
        keepOnReload: true
        actionsSupported: true
        bodySupported: true
        bodyMarkupSupported: true
        imageSupported: true
        persistenceSupported: true
        onNotification: n => {
            n.tracked = true;
            if (root.dnd && n.urgency !== NotificationUrgency.Critical) return;
            root.popups = [n, ...root.popups].slice(0, root.maxPopups);
        }
    }

    function unpop(n) { popups = popups.filter(p => p && p !== n); }
    function dismiss(n) {
        if (!n) return;
        unpop(n);
        lastDismissed = { app: n.appName, summary: n.summary, body: n.body };
        n.dismiss();
    }
    function newest() { return popups[0] ?? history[history.length - 1] ?? null; }
    function dismissLast() { dismiss(newest()); }
    function dismissAll() { for (const n of [...history]) n.dismiss(); popups = []; }
    function dismissSummary(text) { dismiss(history.find(n => n.summary.includes(text)) ?? null); }
    function invokeLast() {
        const n = newest();
        const a = n?.actions.find(a => a.identifier === "default") ?? n?.actions[0];
        if (a) a.invoke();
    }
    // Re-sends the last dismissed one (the server can't un-dismiss).
    function restoreLast() {
        if (lastDismissed) Quickshell.execDetached(["notify-send", "-a", lastDismissed.app, lastDismissed.summary, lastDismissed.body]);
    }
    function toggleDnd() { dnd = !dnd; if (dnd) popups = []; }
}
```

```js
.pragma library
// Subsequence match: 0 = no match; higher is better. Prefix and word-start
// hits beat scattered letters, so "fir" ranks Firefox above "Font Viewer".
function score(query, text) {
    if (!query) return 1;
    const q = query.toLowerCase(), t = (text || "").toLowerCase();
    if (t.startsWith(q)) return 100 - Math.min(t.length, 50) / 10;
    const i = t.indexOf(q);
    if (i >= 0) return 60 - i / 10 + (/[\s\-_.]/.test(t[i - 1]) ? 20 : 0);
    let ti = 0, s = 0;
    for (const c of q) {
        const k = t.indexOf(c, ti);
        if (k < 0) return 0;
        s += k === ti ? 2 : 1;
        ti = k + 1;
    }
    return 10 + s;
}
```

```bash
# shellcheck shell=bash
# mbm dmenu: options on stdin -> the shell's launcher in dmenu mode -> the
# choice on stdout. Exit 1 on cancel, timeout, or when the shell isn't running.
# The shell answers through a FIFO: "1\n<choice>\n" or "0\n\n".

dmenu_main() {
  local prompt="" select=0 input_only=false dir status="" choice=""
  while (($#)); do
    case "$1" in
      -p | --prompt) prompt="${2:?--prompt needs a value}"; shift ;;
      --select) select="${2:?--select needs a number}"; shift ;;
      --input-only) input_only=true ;;
      *) echo "mbm dmenu: unknown option $1" >&2; return 2 ;;
    esac
    shift
  done
  [[ $select =~ ^[0-9]+$ ]] || { echo "mbm dmenu: --select needs a number" >&2; return 2; }

  dir="$(mktemp -d "${XDG_RUNTIME_DIR:-/tmp}/mbm-dmenu.XXXXXX")"
  # shellcheck disable=SC2064 # expand $dir now: it's local
  trap "rm -rf '$dir'" RETURN
  if [[ $input_only == true ]]; then : >"$dir/options"; else cat >"$dir/options"; fi
  mkfifo "$dir/result"

  qs -c mbm ipc call dmenu open "$prompt" "$dir/options" "$dir/result" "$select" "$input_only" >/dev/null 2>&1 \
    || { echo "mbm dmenu: the mbm shell isn't running" >&2; return 1; }
  { IFS= read -r status && IFS= read -r choice; } < <(timeout 600 cat "$dir/result") || return 1
  [[ $status == 1 ]] || return 1
  printf '%s\n' "$choice"
}
```

```qml
// Lock before suspend: hold a logind *delay* inhibitor so sleep waits (up to
// InhibitDelayMaxSec) until the lock surface is up, then release it.
Singleton {
    id: root
    property bool pending: false
    signal preparingForSleep()
    signal resumed()

    Process {
        id: inhibitor
        running: Settings.lockOnSleep
        command: ["systemd-inhibit", "--what=sleep", "--mode=delay", "--who=mbm shell",
                  "--why=Lock the screen before sleep", "sleep", "infinity"]
    }
    function release() { pending = false; inhibitor.running = false; }

    Process {
        id: monitor
        running: true
        command: ["gdbus", "monitor", "--system", "--dest", "org.freedesktop.login1", "--object-path", "/org/freedesktop/login1"]
        stdout: SplitParser {
            onRead: line => {
                if (!line.includes("PrepareForSleep")) return;
                if (line.includes("(true,)")) { root.pending = true; root.preparingForSleep(); }
                else if (line.includes("(false,)")) { root.resumed(); inhibitor.running = Settings.lockOnSleep; }
            }
        }
        onExited: again.start()
    }
    Timer { id: again; interval: 2000; onTriggered: monitor.running = true }
```

- [ ] **Step 3: Write `lock/Lock.qml`**

```qml
import Quickshell
import Quickshell.Io
import Quickshell.Wayland
import Quickshell.Services.Pam
import QtQuick
import "../services"

Scope {
    id: root
    property string password: ""
    property string status: ""        // "", "checking", "failed"
    property int attempts: 0
    readonly property bool locked: wl.locked
    readonly property bool secure: wl.secure
    readonly property string flagPath: Quickshell.env("HOME") + "/.local/state/mbm/locked"
    readonly property string instance: Quickshell.env("HYPRLAND_INSTANCE_SIGNATURE") ?? ""
    signal unlockedNow()

    function lock(fromSleep) {
        if (wl.locked) return;
        ShellState.closePopups();               // popups give up the keyboard; a waiting dmenu gets "cancel"
        ShellState.locked = true;
        wl.locked = true;
        flag.setText(instance);                 // a restarted shell re-locks from this (same session only)
        Quickshell.execDetached(["hyprctl", "switchxkblayout", "all", "0"]);
        Quickshell.execDetached(["sh", "-c", "pgrep -x 1password >/dev/null && 1password --lock"]);
        if (!fromSleep) displayOff.restart();
    }
    function submit() {
        if (pam.active || password === "") return;
        status = "checking";
        pam.start();
    }
    function finishUnlock() {
        wl.locked = false;
        ShellState.locked = false;
        status = ""; password = ""; attempts = 0;
        displayOff.stop();
        Quickshell.execDetached(["rm", "-f", flagPath]);
        unlockedNow();
    }

    // Like slievr-system-lock: screens off shortly after a manual lock (any key wakes them: misc:key_press_enables_dpms).
    Timer { id: displayOff; interval: 3000; onTriggered: if (wl.locked) Quickshell.execDetached(["hyprctl", "dispatch", "dpms", "off"]) }

    FileView {
        id: flag
        path: root.flagPath
        atomicWrites: true
        onLoaded: if (text().trim() !== "" && text().trim() === root.instance) root.lock(true)
    }
    Component.onCompleted: Quickshell.execDetached(["mkdir", "-p", Quickshell.env("HOME") + "/.local/state/mbm"])

    PamContext {
        id: pam
        config: "mbm-lock"
        onPamMessage: if (responseRequired) respond(root.password)
        onCompleted: result => {
            if (result === PamResult.Success) root.finishUnlock();
            else { root.status = "failed"; root.attempts++; root.password = ""; }
        }
        onError: { root.status = "failed"; root.password = ""; }
    }

    WlSessionLock {
        id: wl
        LockSurface { lockRoot: root }
    }
}
```

```qml
import Quickshell
import Quickshell.Hyprland
import QtQuick

// Captures one key combo. While recording, Hyprland sits in the empty
// `mbm-record` submap (generated with binds.conf), so its binds don't fire and
// every key reaches this window. A 10 s guard and SUPER+CTRL+ALT+Escape (in the
// submap) make sure nobody is left stuck there.
FocusScope {
    id: rec
    property bool active: false
    signal recorded(string mods, string key)
    signal cancelled()

    function start() { active = true; Hyprland.dispatch("submap mbm-record"); catcher.forceActiveFocus(); guard.restart(); }
    function stop() { if (!active) return; active = false; guard.stop(); Hyprland.dispatch("submap reset"); }
    Component.onDestruction: stop()

    Timer { id: guard; interval: 10000; onTriggered: { rec.stop(); rec.cancelled(); } }

    readonly property var names: ({
        [Qt.Key_Return]: "RETURN", [Qt.Key_Enter]: "RETURN", [Qt.Key_Space]: "SPACE", [Qt.Key_Tab]: "TAB",
        [Qt.Key_Backtab]: "TAB", [Qt.Key_Backspace]: "BACKSPACE", [Qt.Key_Delete]: "DELETE", [Qt.Key_Escape]: "ESCAPE",
        [Qt.Key_Left]: "LEFT", [Qt.Key_Right]: "RIGHT", [Qt.Key_Up]: "UP", [Qt.Key_Down]: "DOWN",
        [Qt.Key_Home]: "HOME", [Qt.Key_End]: "END", [Qt.Key_PageUp]: "Page_Up", [Qt.Key_PageDown]: "Page_Down",
        [Qt.Key_Insert]: "INSERT", [Qt.Key_Print]: "PRINT", [Qt.Key_Comma]: "COMMA", [Qt.Key_Period]: "PERIOD",
        [Qt.Key_Slash]: "slash"
    })
    readonly property var modifierKeys: [Qt.Key_Shift, Qt.Key_Control, Qt.Key_Alt, Qt.Key_Meta, Qt.Key_Super_L, Qt.Key_Super_R, Qt.Key_AltGr]

    Item {
        id: catcher
        focus: rec.active
        Keys.onPressed: e => {
            e.accepted = true;
            if (!rec.active || rec.modifierKeys.includes(e.key)) return;     // wait for the real key
            const mods = [];
            if (e.modifiers & Qt.MetaModifier) mods.push("SUPER");
            if (e.modifiers & Qt.ControlModifier) mods.push("CTRL");
            if (e.modifiers & Qt.AltModifier) mods.push("ALT");
            if (e.modifiers & Qt.ShiftModifier) mods.push("SHIFT");
            if (e.key === Qt.Key_Escape && mods.length === 0) { rec.stop(); rec.cancelled(); return; }
            let key = rec.names[e.key];
            if (!key && e.key >= Qt.Key_A && e.key <= Qt.Key_Z) key = String.fromCharCode(e.key);
            if (!key && e.key >= Qt.Key_F1 && e.key <= Qt.Key_F24) key = "F" + (e.key - Qt.Key_F1 + 1);
            // Digits, punctuation, anything else: the xkb keycode, the form today's binds use (code:10 = "1").
            if (!key) key = "code:" + e.nativeScanCode;
            rec.stop();
            rec.recorded(mods.join(" "), key);
        }
    }
}
```

- [ ] **Step 1: Write `cachyos/iso/test/verify-shell.sh`**

```bash
#!/usr/bin/env bash
# End-to-end checks for the mbm shell, run inside the logged-in Hyprland
# session (needs wtype; types the account password for the lock checks):
#   cachyos/vm/vm.sh run 'bash ~/proj/slievr-cachy/cachyos/iso/test/verify-shell.sh'
set -uo pipefail

PASSWORD="${VM_PASSWORD:-TestPass1}"
bad=0
ok() { printf 'PASS  %s\n' "$1"; }
no() { printf 'FAIL  %s\n' "$1"; bad=1; }
is() { if [[ "$2" == "$3" ]]; then ok "$1"; else no "$1 (got: $3)"; fi; }
ipc() { qs -c mbm ipc call "$@" 2>/dev/null; }
state() { ipc shell state | jq -r ".$1"; }
unlock() { wtype "$PASSWORD"; wtype -k Return; sleep 3; }

is "mbm-shell active"            active "$(systemctl --user is-active mbm-shell)"
for d in waybar mako swayosd-server hypridle hyprlock walker elephant polkit-gnome-authentication-agent-1; do
  is "$d not running"            no     "$(pgrep -f "$d" >/dev/null && echo yes || echo no)"
done
is "shell answers IPC"           pong   "$(ipc shell ping)"
is "settings valid"              ""     "$(mbm settings check 2>&1)"
is "generated config present"    3      "$(ls ~/.config/hypr/mbm/*.conf 2>/dev/null | wc -l)"

ipc launcher toggle;  sleep 0.3; is "launcher opens"       true  "$(state launcher)"
ipc launcher toggle;  sleep 0.3; is "launcher closes"      false "$(state launcher)"
ipc quicksettings open wifi; sleep 0.3; is "quick settings opens a picker" wifi "$(state picker)"
ipc quicksettings close
ipc settings open input; sleep 0.5; is "settings opens a page" input "$(state page)"
ipc settings close

notify-send verify-shell hello; sleep 0.5
is "notification recorded"       yes    "$( (( $(ipc notifications count) > 0 )) && echo yes || echo no)"
ipc notifications dismissAll

mbm settings set '.binds["custom.verify"]' '{"mods":"SUPER CTRL ALT","key":"F12","label":"verify","group":"Custom","action":{"exec":"true"}}' && mbm settings apply
is "custom bind reaches Hyprland" 1     "$(hyprctl binds -j | jq '[.[] | select(.description == "verify")] | length')"
mbm settings reset '.binds["custom.verify"]' && mbm settings apply
is "custom bind removed"         0      "$(hyprctl binds -j | jq '[.[] | select(.description == "verify")] | length')"

(printf 'x\ny\n' | mbm dmenu --select 2 >/tmp/verify-dmenu) & sleep 0.8; wtype -k Return; wait
is "dmenu returns the choice"    y      "$(cat /tmp/verify-dmenu)"

ipc lock lock; sleep 1
is "locks"                       locked "$(ipc lock status)"
wtype not-the-password; wtype -k Return; sleep 3
is "wrong password stays locked" locked "$(ipc lock status)"
systemctl --user kill --signal=SIGKILL mbm-shell; sleep 4
is "shell restarted after crash" active "$(systemctl --user is-active mbm-shell)"
is "still locked after crash"    locked "$(ipc lock status)"
unlock
is "right password unlocks"      unlocked "$(ipc lock status)"

exit $bad
```
