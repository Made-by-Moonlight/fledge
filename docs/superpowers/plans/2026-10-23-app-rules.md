# Per-app window rules: plan

Spec: `docs/superpowers/specs/2026-10-23-app-rules-design.md`.
Branch: `app-rules`. Everything runs in the `cachyos-test` VM.

## 0. Spikes (done, in the VM)

- [x] `hl.window_rule` takes `opacity`, `workspace`, `monitor` (`desc:…` or
      a connector); unknown fields are refused.
- [x] A reload re-applies opacity rules to open windows, and dropping the
      rule reverts them.
- [x] `window.set_prop` sticks across reloads and can't be unset: not used.

## 1. Settings and the generator

- [x] `check.jq`: `windows` (opacity) and `apps` (opacity, workspace,
      monitor; not both placements); the schema in the shell spec.
- [x] `settings.sh`: `apps` entries set to `null` drop out of the merge;
      `apply` renders `gen-apps.jq` into `apps.lua` with the others.
- [x] `gen-apps.jq`: the default-opacity rule, then per class its opacity
      (`override`) and placement rules, each guarded like `rules.lua`'s, one
      notification naming the ones that failed. Classes regex-escaped.
- [x] `hyprland.lua`: load `apps.lua` after `workspaces.lua`.
- [x] Defaults: `windows.opacity` and the `apps` entries from the table in
      the spec; `rules.lua` loses those rules, the `-default-opacity` opt-outs
      and the `terminal` tag (the browser tags stay: Chromium tiles by them).
- [x] Tests: `check` cases, `expected-apps.lua` fixture, the stub runs it
      (`hl.window_rule` added to `hl-stub.lua`), a failing rule costs only
      itself, `null` removes an entry, load order in `test-hypr-load.sh`.

## 2. The page

- [x] `Settings.qml`: `windowOpacity`, `apps`.
- [x] `settings/pages/Apps.qml`: Default sliders; Open now (by class, from
      `ToplevelManager.toplevels`' app ids) and Configured lists; the row editor (opacity
      Default/Own with two sliders, Opens on Anywhere/Workspace/Monitor,
      Forget); Add by class. Slider saves debounced 400 ms + on release.
- [x] `SettingsWindow.qml`: the Apps page in the list.

## 3. Checks

- [x] `verify-shell.sh`: default opacity on an open kitty; an app opacity
      change reaches it after apply, reset brings the default back; a
      workspace entry places a new kitty; the page opens and lists kitty.
- [x] Full `verify-shell.sh`, unit tests, shellcheck, `check-names.sh`;
      screenshot the page.
