# Image viewer

Satty is installed for annotating screenshots but can become the default image
handler. It cannot browse pictures and folders. Install gThumb, which has a
folder browser and thumbnails, and use it for ordinary image files.

On first setup, replace an absent or Satty image association with gThumb for
the common formats it supports. Keep associations to other applications and
remember that the defaults were seeded, so a later user choice survives an
upgrade. Keep Satty for screenshots. gThumb follows the existing GTK dark
preference; a full match to the fledge palette belongs to the planned app
theme project, not a global GTK override here.

Verify installation and associations in the VM, open an image and navigate
folders, and check that repeat setup preserves a changed association.
